Usage Note
Pick adjacent states so their fill patterns differ. Two identical states will merge visually — that is accepted only for consecutive .complete steps. Do not add gaps, margins, or dividers between indicators. Use .progress.animated for an opt-in drifting stripe; animation is removed under prefers-reduced-motion.
Semantic Guidance
  • .complete — step is done and verified.
  • .progress — step is started but not finished.
  • .review — step is complete and pending verification.
  • .active — the current step in focus.
  • .next — the step queued immediately after active.
  • .step — a step that has not started.

Block
import { readJSON, writeJSON } from './fs';
import { extractTags, validateSchema } from './pipeline';

// ── Load source board ─────────────────────────────────────
const board   = await readJSON('boards/aerospace.json');
const images  = board.images.filter(i => i.reviewed);
const refs    = images.slice(0, 5);

// ── Run extraction & validation ───────────────────────────
const tags    = await extractTags(refs);
const report  = validateSchema(tags, 'v2');

await writeJSON('output/tags.json',       tags);
await writeJSON('output/report.json',     report);
await writeJSON('output/manifest.json',   { count: tags.length });

console.log(`Tagged ${tags.length} refs in ${Date.now() - t0}ms`);
